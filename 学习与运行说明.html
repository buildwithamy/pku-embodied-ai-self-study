学习指南

从零开始，怎样读这套教程

先从一个具体任务入手，再逐步学习完成它需要的数学与编程。第一章可以直接开始；遇到陌生概念时，沿着章内的热身练习补齐基础。

开始前需要什么

概念阅读只需能使用浏览器。公式学习会用到向量、矩阵乘法、三角函数、导数和概率的基础概念；代码练习需要Python基础。第1章准备了NumPy、坐标、旋转与运动学热身，遇到不熟悉的概念可先完成这些练习。

阶段先掌握能解释或完成什么
第1章观察—动作循环说清楚识别杯子与拿起杯子的区别
第2—4章向量、矩阵、三角函数换坐标、计算末端位置、规划路径、理解反馈控制
第5—7章点云、最小二乘的直观含义解释物体位姿、配准、接触约束与抓取候选
第8—9章条件概率、期望、梯度区分示范学习与回报优化，说明策略和价值函数
第10章前九章的输入、输出与条件画出一个综合机器人的感知、决策、执行与反馈链

每章读三遍，不必一次读完

  1. 建立直觉：读开头、例子和图，回答“为什么需要这个概念”。
  2. 掌握方法：看公式，逐个说出符号含义、坐标约定和适用条件；对照英文课件与中文翻译。
  3. 检验理解：完成自测，运行小例子，改变一个参数并解释结果。能复述结论后，再练习推导。

正文用例子解释概念，逐页翻译则对应原始PDF中的文字与图示。阅读公式时，先确认本章的符号约定；使用其他代码库时，再核对四元数的分量顺序并做相应转换。

打开教程

推荐双击本文件夹中的打开教程.cmd。它启动仅监听本机的Python静态服务器，并打开本教程目录。保持服务器窗口运行；结束阅读后关闭窗口。

也可在本文件夹打开PowerShell，运行：

python -m http.server 8000 --bind 127.0.0.1

然后访问 http://127.0.0.1:8000/。如果系统通过Python启动器安装，使用py -3代替python。端口已占用时改用8001，并访问对应端口。

运行基础CPU练习

在本文件夹的PowerShell中建立单独的环境，避免影响其他项目。下面的安装需要联网；已安装依赖后，基础例子可以离线运行。

python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-cpu.txt
.\.venv\Scripts\python.exe ch01\homework01\warmup.py
.\.venv\Scripts\python.exe ch02\examples.py
.\.venv\Scripts\python.exe ch03\examples.py

第4—9章也各有 examples.py。先用这些小规模CPU演示观察算法怎样工作，结合章内说明解释输出和图像，再通过课程作业练习完整的训练与评估流程。

四个课程作业

作业入口建议顺序与环境
1 · 旋转与正运动学第1章实践先做热身；读第2—3章后回到原作业实现函数。保留学生TODO。
2 · 位姿估计与抓取第5章实践先学第5—7章；完整工程、数据和深度学习环境以原作业说明为准。
3 · PPO与机器人控制第9章实践先学第8—9章；原作业的仿真器、GPU与依赖需要单独配置。
4 · 机器人协同作业第10章实践综合运用课程知识；按原作业安装对应控制、感知与仿真组件。

各章保留了原始作业的链接、数据和依赖说明。准备使用真实机器人时，先完成仿真验证，再按平台规程配置限位、速度和急停，逐步检查动作执行情况。

英文、公式和资料怎样查

术语与符号汇总常见缩写与中文解释；各章术语表给出本章语境。课件入口按原讲次和页号组织，不改动原PDF。正文图片可以点开原图，逐页翻译中的预览可打开原PDF对应页。窄屏上的宽表格和长公式可以在区块内横向滚动。

下载完整教程后，正文、图片、公式和PDF都可以离线阅读。外部论文、项目、视频和依赖安装需要联网。尝试技术动态中的模型时，按对应项目的文档准备环境与硬件；本教程的基础练习使用独立的CPU环境。
